## Screenshot placeholders

Store product screenshots for README/docs in this folder using the placeholder names below.

### Required placeholder files

1. `android-match-setup.png`
   - Purpose: Android Match Setup screen with required and optional sections visible.
2. `desktop-match-setup.png`
   - Purpose: Desktop Match Setup in expanded layout.
3. `desktop-theme-menu.png`
   - Purpose: Desktop `Theme` menu showing `System`, `Light`, and `Dark` options.
4. `desktop-window-restore.png`
   - Purpose: Desktop startup showing restored window size and position.

### Capture guidance

- Prefer PNG format.
- Keep aspect ratio close to the target platform defaults.
- Avoid personal/sensitive data in captures.
- Replace placeholder references in the root `README.md` by adding image markdown once screenshots are available.
